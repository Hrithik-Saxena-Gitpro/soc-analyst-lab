## 📋 Investigation Methodology

I aim to document each investigation using a consistent workflow:

1. **Objective** — Define the security question or problem.
2. **Scope** — Identify the systems, files, or evidence being examined.
3. **Evidence Collection** — Record relevant observations and artefacts.
4. **Analysis** — Investigate evidence and test reasonable hypotheses.
5. **Findings** — Explain what the evidence supports.
6. **Risk Assessment** — Describe potential impact and severity.
7. **Recommendations** — Suggest practical defensive actions.
8. **Lessons Learned** — Document knowledge gained and possible improvements.



## 📈 Portfolio Standards

Every project should aim to include:

- A clear objective and scope
- Tools and techniques used
- Reproducible analysis steps where appropriate
- Evidence and observations
- Findings supported by evidence
- Risk and impact assessment
- Defensive recommendations
- References and lessons learned
